# Ghost Script

Ghost Script is a haunted handwriting game for people who can read Chinese characters but can no longer write them: character amnesia (提笔忘字). It is for heritage learners and second-language learners, so the interface is in English.

**The premise:** phonetic typing caused the forgetting, so Ghost Script brings back the shape-based keyboard that phonetic input displaced for most typists. Cangjie (倉頡輸入法), developed in the 1970s by Chu Bong-Foo, builds every character from basic shapes. In the game, each forgotten character is a ghost: you summon it by typing its Cangjie code, shape by shape, then lay it to rest by writing it by hand. Ghosts you struggle with come back to haunt you sooner.

Built for **Kiroween 2026**, category **Resurrection**.

## Play it

Play Ghost Script at https://taki-pro.github.io/ghost-script/. It is a static site that runs in the browser with no account. Your progress is saved only in that browser (in `localStorage`).

## Run it locally

Prerequisites: Node and npm.

1. From the repository root, install dependencies. One install covers the root and the `app` workspace:

   ```
   npm install
   ```

2. Start the dev server:

   ```
   npm run dev -w app
   ```

3. Open the localhost URL that Vite prints.

Never start the dev server with `--host`. Leaving it out keeps the server on localhost only.

Run the tests with `npm test` and make a production build with `npm run build -w app` (output in `app/dist`). See [Usage](#usage) for details.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`. The workflow runs `npm ci`, the full `npm test`, then `npm run build -w app`, and deploys `app/dist` to GitHub Pages only if every step passes.

One-time repository setting: Settings → Pages → Build and deployment → Source: "GitHub Actions".

## Usage

### Build the dataset

Prerequisites: Node and npm, and the raw datasets present under `data/raw/` (they ship in the repo).

```
npm run build:data
```

This reads `data/character-list.txt`, the three raw datasets under `data/raw/`, and `data/prompt-overrides.csv`, and writes `app/public/data/characters.json` and `data/prompt-review.csv`. It runs fully offline — no network access, no API keys, no runtime LLM calls — and is deterministic: the same inputs always produce byte-for-byte identical output.

### Run the tests

```
npm test
```

Runs the Vitest suite: unit tests, fast-check property-based tests, smoke tests, and the integration test.
