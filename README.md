# Ghost Script

Ghost Script is a haunted handwriting game that brings back the Chinese characters people have forgotten how to write. It targets character amnesia (提笔忘字) — the common experience of being able to read Chinese but no longer recall how to write it by hand after years of phonetic typing. Rather than drilling by repetition, Ghost Script teaches how each character is built, the Cangjie way: structural, component-by-component thinking. It is built for **Kiroween 2026**, category **Resurrection** — the revived "dead technology" is handwriting itself, together with the structural thinking of the Cangjie input method.

## Usage

### Build the dataset

Prerequisites: Node and npm, and the raw datasets present under `data/raw/` (they ship in the repo).

```
npm run build:data
```

This reads `data/character-list.txt`, the three raw datasets under `data/raw/`, and `data/prompt-overrides.csv`, and writes `app/public/data/characters.json` and `data/prompt-review.csv`. It runs fully offline — no network access, no API keys, no runtime LLM calls — and is deterministic: the same inputs always produce byte-for-byte identical output.

### Run the tests

```
npm test
```

Runs the Vitest suite: unit tests, fast-check property-based tests, smoke tests, and the integration test.
